How TOTP works

TOTP (Time-based One-Time Password, RFC 6238) generates a short numeric code that changes every 30 seconds (or 60). The algorithm: (1) Compute T = floor(unixTimestamp / period) as an 8-byte big-endian integer. (2) Compute HMAC-SHA1(secret, T) using the decoded Base32 secret as the key. (3) Extract a 4-byte dynamic offset from the last byte of the HMAC. (4) Truncate to 6 (or 8) digits: code = (hmac[offset..offset+3] & 0x7FFFFFFF) % 10^digits. Both the server and client perform this independently — if the resulting codes match, authentication succeeds. The code changes every period window, so a captured code is useless seconds later.
