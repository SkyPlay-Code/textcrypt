How metadata stripping works

JPEG files embed metadata in EXIF (Exchangeable Image File Format) segments — APP1 markers containing camera settings, GPS coordinates, device serial numbers, timestamps, and software. This tool strips all of it by redrawing the image through an HTML Canvas: the image is decoded and re-encoded as a new file from pixel data alone — Canvas never carries over any original file structure or metadata segments. The output is a pixel-identical (within JPEG compression limits) but entirely clean image. For maximum privacy, select PNG output (lossless and guaranteed clean). Note: GPS and EXIF detection below is a basic heuristic parser — the stripping itself is complete regardless of what metadata is detected.
