How ECDH works

Elliptic-curve Diffie–Hellman (ECDH) solves the key distribution problem: how can two parties establish a shared secret over an untrusted channel without transmitting it? Each party generates a public/private key pair on the same elliptic curve (P-256 here). The mathematical property a·(b·G) = b·(a·G) means both sides independently arrive at the same curve point — the shared secret. An eavesdropper who intercepts both public keys cannot compute the secret without solving the elliptic curve discrete logarithm problem (considered computationally infeasible). The raw shared secret is used as AES-256-GCM key material here to demonstrate hybrid encryption.
