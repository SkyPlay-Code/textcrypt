How PBKDF2 works

PBKDF2 (Password-Based Key Derivation Function 2) is designed to be slow by repeating an HMAC computation a configurable number of times (iterations). This makes brute-force and dictionary attacks expensive: 250,000 iterations means an attacker must perform 250,000 HMAC operations per password guess. A random salt ensures the same password produces a different hash each time, defeating precomputed rainbow table attacks. The output record format pbkdf2:ALGO:ITER:SALT:HASH stores all parameters needed for verification — similar to how databases like Django or PostgreSQL store password hashes.
