How it works · .aegis binary format

The entire file is read into memory as raw bytes and encrypted with AES-256-GCM (key derived via PBKDF2, 250,000 iterations). The result is wrapped in a custom binary container that stores the original filename so it is restored automatically on decryption. The GCM authentication tag guarantees that any file corruption or tamper attempt is detected before any bytes are returned.
