ChaCha20-Poly1305

✔ RFC 8439
How it works

ChaCha20-Poly1305 is an AEAD (Authenticated Encryption with Associated Data) cipher. WebCrypto does not expose it natively in browsers, so this uses a pure-JS RFC 8439 implementation. Your password is run through PBKDF2 (SHA-256, 250,000 iterations) to produce a 256-bit key. ChaCha20 generates a keystream from that key + a random 96-bit nonce; XORing with the plaintext produces ciphertext. Poly1305 then computes a 128-bit authentication tag over the ciphertext. On decryption the tag is verified first (before any plaintext is returned) — this is the key security property of AEAD. Output format: [salt 16B][nonce 12B][tag 16B][ciphertext] → Base64.
