Each row shows: Offset (byte position from file start in hex or decimal), Hex bytes (raw byte values in hexadecimal, grouped by the selected row width), and ASCII panel (printable characters shown as-is, non-printable bytes shown as .). Colour coding helps spot patterns: null bytes, whitespace, printable text, control characters, and high-range bytes are each distinctly coloured. The search field accepts either space-separated hex pairs (e.g. FF D8 FF E0) or plain ASCII text.
