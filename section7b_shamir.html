How Shamir's Secret Sharing works

Shamir's scheme is based on polynomial interpolation. To split a secret with a (K, N) threshold: each byte of the secret becomes the constant term of a random degree-(K-1) polynomial over GF(2⁸) (Galois Field with 256 elements, using AES's irreducible polynomial). N points on this polynomial become the N shares. Any K of those points uniquely determine the polynomial via Lagrange interpolation — recovering the secret (constant term). Crucially, fewer than K shares reveal zero information about the secret: for any set of fewer than K points, every possible secret value is equally consistent with those points (information-theoretic security, same as a one-time pad). Shares are encoded as aegis-sss-v1:shareIndex:base64(shareBytes).
