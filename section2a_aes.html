How it works

Your password is combined with a randomly generated 16-byte salt and run through PBKDF2 (SHA-256, 250,000 iterations) to produce a 256-bit AES key. The plaintext is then encrypted with AES-GCM using a random 12-byte IV. GCM mode provides both encryption and an authentication tag — any tampering is detected on decrypt. The output is [salt 16B][iv 12B][ciphertext+tag] encoded as Base64.
