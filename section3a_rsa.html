How it works

RSA-4096 uses WebCrypto's RSA-OAEP (Optimal Asymmetric Encryption Padding) scheme with SHA-256 as the hash function. The public key encrypts data; only the matching private key can decrypt it. Because RSA can only encrypt data shorter than the key modulus minus padding overhead (~446 bytes for 4096-bit), this tool is suited for short payloads — use it to encrypt a symmetric key (like an AES key) for hybrid encryption in real systems. Keys are exported in standard SPKI (public) and PKCS#8 (private) PEM format, compatible with OpenSSL, Node.js, and most crypto libraries.
