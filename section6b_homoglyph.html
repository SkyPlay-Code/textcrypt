How homoglyphs work

A homoglyph is a character that looks visually identical (or nearly so) to another character in a different Unicode script. For example, the Cyrillic letter а (U+0430) looks the same as the Latin a (U+0061) but is a completely different code point. This is the basis of IDN homograph attacks, where a domain like pаypal.com (Cyrillic а) can look identical to paypal.com in a browser address bar. The technique is used here for educational/security research purposes: understanding how visually spoofed text can fool humans but fail system-level string comparisons.
