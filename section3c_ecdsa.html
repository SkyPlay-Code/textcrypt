How ECDSA works

ECDSA (Elliptic Curve Digital Signature Algorithm) proves that a message was created by someone holding a specific private key, without revealing that key. To sign: the message is hashed (SHA-256 or SHA-384), and the hash is combined with the private key and a random nonce to produce a signature — two integers (r, s) on the chosen curve. To verify: anyone with the public key can confirm whether the (r, s) pair is consistent with the message hash. If the message was altered even by a single byte, verification fails. This enables non-repudiation: the signer cannot later deny having signed the message.
