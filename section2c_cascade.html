Cascade Encryptor

✔ Double Layer
Plaintext → AES-GCM (Password 1) → AES-GCM (Password 2) → Base64 Output
🔒 Inner Layer — Password 1 (applied first)
🔐 Outer Layer — Password 2 (applied second)
🔐 Outer Layer — Password 2 (stripped first)
🔒 Inner Layer — Password 1 (stripped second)
How it works

Cascade encryption wraps your payload in two independent AES-256-GCM layers, each with its own randomly generated salt and IV, and each locked by a separate password. Encryption order: Password 1 is applied first (inner), then Password 2 wraps the result (outer). Decryption is the reverse: outer layer (Password 2) is removed first, then inner (Password 1). An attacker must fully break both layers to recover any plaintext — they are independent and there is no key relationship between them.
