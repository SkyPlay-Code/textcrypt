About these algorithms

SHA-256 / SHA-384 / SHA-512 are part of the SHA-2 family standardised by NIST. They are considered cryptographically secure and suitable for digital signatures, certificates, and integrity checking. SHA-1 (160-bit) has known collision vulnerabilities — SHAttered (2017) demonstrated a practical SHA-1 collision — avoid for security-critical use, though it still appears in Git commit hashes and legacy systems. MD5 (128-bit) is completely broken for security purposes; collisions can be found in seconds. It survives only as a fast non-cryptographic checksum (e.g. verifying accidental file corruption, not adversarial tampering). MD5 is computed with a pure-JS polyfill since the Web Crypto API intentionally omits it.
