Information-Theoretic Security
⚠️ A true OTP is only secure if the keyfile is: (1) truly random, (2) at least as long as the message, (3) never reused, and (4) kept completely secret. Reusing a key catastrophically breaks security (known as the "two-time pad" attack). Use the keyfile only once, then destroy it.

How the One-Time Pad works

The OTP is the only known encryption scheme with information-theoretic security — it is mathematically proven to be unbreakable when used correctly, because every possible plaintext of the correct length is equally likely given the ciphertext alone. Encryption: ciphertext[i] = plaintext[i] XOR key[i]. Decryption: plaintext[i] = ciphertext[i] XOR key[i] (XOR is its own inverse). The keyfile is generated using crypto.getRandomValues — a CSPRNG — ensuring the key is truly unpredictable. Security collapses entirely if the key is reused — given two ciphertexts encrypted with the same key, XORing them cancels the key and reveals a combination of the two plaintexts.
