How file integrity checking works

A cryptographic hash function maps a file of any size to a fixed-length digest (fingerprint). SHA-256 produces a 256-bit (64 hex character) digest; SHA-512 produces 512 bits. The key property is collision resistance: it is computationally infeasible to find two different files with the same hash, and even a single byte change in the file produces a completely different hash (avalanche effect). This means you can verify a file downloaded months later hasn't been corrupted or tampered with by comparing its hash to the original stamp.
